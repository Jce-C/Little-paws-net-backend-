# Prompt listo para copiar

Actúa como especialista en diseño de interfaces y animación web vinculada al scroll.

Adjunto un paquete de Little Paws Net. Lee primero BRIEF.md, después demo/README.md y el código de la demo. Revisa las capturas y el video de referencia. Usa el DESIGN.md de Structured como inspiración de composición, no como identidad obligatoria.

Quiero que complementes y mejores esta demo aislada. Lo más importante es la coreografía: primero entra la fotografía sola; al avanzar el scroll aparecen por separado el título, la tarjeta y los contenidos; hay una pausa de lectura; después se retiran para introducir la siguiente escena. Al subir debe revertirse de forma natural. Evita que todo entre junto o que solo se desplace una tarjeta pegada a una foto.

Conserva el logo del perrito, los colores crema/marrón/beige/verde y la coherencia con el Figma móvil enlazado en el brief. No generes imágenes con IA. Usa los recursos incluidos o recursos web con licencia reutilizable, documentando sus créditos. No cambies el backend ni inventes datos reales.

Mejora composición, profundidad, encuadres, ritmo y transición entre escenas, con una versión móvil cuidada. El texto debe tener un estado estable y legible. Mantén navegación por capítulos, salida rápida, teclado, foco de diálogos y movimiento reducido. No secuestres el scroll ni dependas de un video para simular la interfaz.

Entrega una propuesta concreta y, si tienes capacidad de programación, una mini página funcional con todos sus archivos. Prefiere HTML/CSS/JavaScript sin instalación; justifica cualquier dependencia adicional. Explica qué cambiaste, qué recursos usaste y qué límites tiene la propuesta. Si falta algún recurso, especifica nombre, dimensiones y formato en lugar de sustituir la identidad.

El resultado se usará para decidir después el STYLE.md del panel completo. Por ahora quiero mejorar y validar esta exploración, no rediseñar todo el sistema.
